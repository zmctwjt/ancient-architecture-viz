## 修复文化页联动筛选功能

**问题**：建筑文化页面点击朝代筛选按钮后图表数据没有变化。

**根因分析**：
1. `chart.dispose()` 后 DOM 元素上的 `_echarts_instance` 属性未被清除，导致 `echarts.getInstanceByDom(dom)` 返回已销毁的实例
2. `initData` 使用 `requestAnimationFrame` 延迟调用 `initChartsForTab`，但 `reinitWithFilter` 的 `await initData()` 不会等待 RAF 回调完成
3. `safeInitChart` 使用 `notMerge=false` 无法强制刷新数据

**修复内容**（`src/view/culture/main.js`）：
1. `safeInitChart`：增加 `chart.isDisposed()` 检查，清除 `_echarts_instance` 属性，使用 `notMerge=true` 强制刷新
2. `reinitWithFilter`：dispose 后遍历所有 DOM 清除 `_echarts_instance` 属性，增加调试日志
3. `initData`：移除 `requestAnimationFrame`，改为同步直接调用 `initChartsForTab`
4. `filterByDynasty`：增加 console.log 输出匹配数量，便于调试验证

**验证**：`npm run build` 构建成功。

## 修复文化页朝代筛选后全部无数据

**问题**：建筑文化页面不选朝代时有数据，但点击任何朝代筛选后所有图表都显示"暂无数据"。

**根因**：`culture_processed.json` 中民居（residence）的8条数据 `朝代` 字段全部为空字符串。`filterByDynasty` 中 `matchDynastyGroup("", "明清")` 返回 `false`，所以民居数据全被过滤掉了。虽然官府/皇宫/桥梁有朝代字段，但如果只选了"先秦"，这些类别的朝代范围（"隋—清"、"明永乐—清宣统"等）也匹配不上，导致全部为空。

**修复**：给 `public/data/culture_processed.json` 中民居的8条数据添加 `朝代` 字段：
- 四合院：周—清
- 土楼：宋—清
- 徽派民居：明—清
- 吊脚楼：唐—清
- 蒙古包：汉—清
- 碉楼：明—清
- 干栏式建筑：周—清
- 窑洞：周—清

**验证结果**（筛选匹配测试）：
- 先秦：3民居 + 1官府 = 4类有数据
- 秦汉：1民居 + 2官府 = 3类有数据
- 隋唐：1民居 + 2官府 + 1桥梁 = 4类有数据
- 宋元：1民居 + 5桥梁 = 2类有数据
- 明清：8民居 + 5官府 + 4皇宫 + 3桥梁 = 全部有数据

**验证**：`npm run build` 构建成功。

## 修复民居筛选、坐标轴截断、无意义图表

### 1. 修复民居文化筛选不生效
**问题**：点击朝代筛选后，民居文化图表无变化。

### 2. 修复坐标轴文字显示不全
**问题**：官府、皇宫、桥梁等页面 x/y 轴标签被截断或重叠。
**修复**：统一调整所有带旋转标签的图表 `grid.bottom: '25%'`（原 20%），横向条形图 `grid.left: '30%'`（原 20-25%），并补充 `interval: 0` 确保标签全显。

### 3. 替换无分析意义的图表
**问题**：大量图表使用 `countByField` 统计分类字段（名称/功能/类型/布局特征/屋顶形式/规制等级），但数据集每类仅1条，导致柱高全为1，无分析价值。
**修复**（`src/view/culture/main.js`）：
- **民居**：
  - `residenceRadar`（硬编码雷达图）→ **气候适应特征**柱状图（从`气候适应`字段提取关键词）
  - `residenceSymbol`（硬编码散点图）→ **地区分布**环形图（从`地区`字段统计）
- **官府**：
  - `officialLevel`（名称统计，全为1）→ **主要建筑元素**柱状图（从`主要建筑`数组提取殿/堂/楼/阁等频次）
  - `officialLayout`（功能统计，全为1）→ **文化内涵关键词**柱状图（从`文化内涵`提取）
  - `officialEvolution`（规制等级，全为1）→ **全国遗存数量**横向条形图（从`总数_全国`文本提取数字）
- **皇宫**：
  - `palaceLayout`（布局特征，全为1）→ **核心建筑类型**柱状图（从`核心建筑`数组提取）
  - `palaceLevel`（屋顶形式，全为1）→ **世界遗产时间线**横向条形图（从`世界遗产`提取年份）
  - `palaceDecor`（核心建筑数量雷达图）→ **规模vs建筑数量**散点图（x轴占地，y轴建筑间数，气泡大小为核心建筑数）
- **桥梁**：
  - `bridgeType`（类型统计，全为1）→ **跨度对比**横向条形图（从`跨度_米`排序）
  - `bridgeCulture`（文化意义散点图，仅"工程"命中）→ **技术特色关键词**柱状图（从`技术特色`提取拱/梁/基础/榫卯等）

**新增辅助函数**：`countArrayField`、`extractBuildingElements`、`extractNumberFromText`。

### 4. 更新图表标题
`src/view/culture/index.html` 中6个卡片标题同步更新为新的图表含义。
