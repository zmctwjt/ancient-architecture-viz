## 学习分析 Gitee 参考项目：4-c-web

深入研究了 https://gitee.com/jieyujun/4-c-web 项目，这是一个已晋级的25届全国大学生计算机设计大赛数据可视化赛道作品，主题为"千年观天——基于Three.js的天文三维可视化平台"。用户将以该项目为参考，实现自己的数据可视化项目。

### 项目技术栈
- **构建工具**：Vite 6.2.1（MPA多页面应用）
- **3D渲染**：Three.js 0.172.0（粒子系统/星轨）
- **图表库**：ECharts 5.6.0 + echarts-liquidfill 3.1.0（水波效果）
- **动画库**：GSAP 3.12.7 + Tween.js 25.0.0
- **适配方案**：flexible.js（rem适配）
- **其他**：jQuery 3.7.1、ogl（轻量级WebGL）、dat.gui（调试）、less（CSS预处理）

### 关键实现细节
1. **旭日图数据**：四象(青龙/朱雀/白虎/玄武) → 黄道12星座 → 24节气 → 72候
2. **颜色插值函数**：`interpolateColor` 实现浅蓝→深绿渐变色
3. **流星背景动效**：每2秒随机生成1-6个meteor div，CSS动画+animationend销毁
4. **进度条**：读取兄弟节点文字值，以40为最大值动态计算宽度%
5. **flexible.js**：移动端适配，各大屏均独立引入
6. **深色科技风**：背景深色，坐标轴白色透明度处理，青蓝色系图表

## 制定建筑可视化项目整体方案（2026-04-20 17:57）

### 项目定名
**"千年营造·华夏砖木"——中国古代建筑数据可视化平台**

### 页面结构（5页MPA）
1. **home** — 首页总览（粒子动效 + 四入口 + 数据概览）
2. **achievement** — 建筑成就大屏（地图+玫瑰图+极坐标+进度条）
3. **scientist** — 杰出科学家大屏（关系图+时间轴+人物卡片）
4. **literature** — 建筑著作大屏（时间轴+旭日图+词云）
5. **culture** — 建筑文化大屏（四标签页：民居/官府/皇宫/桥梁）

### 数据来源规划（四个爬虫）
- spider_ncha.py：国家文物局全国重点文物保护单位（古建筑类）
- spider_architect.py：百度百科 20位建筑师
- spider_books.py：百度百科 10+部建筑典籍
- spider_culture.py：中国非遗网 传统建筑营造技艺

### 视觉规范
- 背景：#0d1117（深夜墨色）
- 主色：#C8A96E古铜金 / #4ECDC4青瓦色 / #E07B54朱砂红
- 字体：思源宋体（标题）/ 思源黑体（正文）
- 特效：飘落叶片替代流星，更契合古建筑意境
