## 优化 common.css 全局样式（Task 1）

### 核心问题
- `.page-container` 的 `overflow: hidden` 会同时截断水平和垂直方向内容，导致图表或长内容被裁切
- `.dashboard-grid` 固定 `height: calc(100vh - 1.2rem)` + `overflow: hidden` 导致图表区域无法扩展，内容被截断
- `.chart-panel` 默认 `overflow: hidden` 会裁剪 ECharts 的 tooltip、legend 等溢出元素
- 各页面重复定义 `.panel-full` 等工具类，未统一放到全局样式

### 优化内容
1. **page-container / page-wrapper**：`overflow: hidden` → `overflow-x: hidden; overflow-y: auto`，允许垂直滚动，仅禁止水平滚动
2. **dashboard-grid**：移除固定 `height` 和 `overflow: hidden`，改用 `min-height`，防止图表被截断
3. **chart-panel**：默认改为 `overflow: visible`，新增 `.overflow-hidden` 修饰类供需要裁剪的场景显式添加
4. **chart-container**：默认 `height: auto`，让页面自行覆盖固定高度，避免与 grid 的 min-height 冲突
5. **新增全局工具类**：
   - 网格列数：`.grid-cols-1/2/3/4`
   - 面板跨列：`.panel-full`、`.panel-half`、`.panel-third`
   - 文本截断：`.text-ellipsis`、`.text-ellipsis-2`、`.text-ellipsis-3`
   - Flex 布局：`.flex`、`.flex-col`、`.items-center`、`.justify-center`、`.gap-sm/md/lg`
6. **z-index 变量化**：`--z-base/chart/header/back-link/modal`，避免层级混乱
7. **响应式增强**：768px 以下 `.dashboard-grid`、`.grid-cols-*`、`.panel-*` 强制单列；769-1200px `.grid-cols-4` 降为2列
8. **构建验证**：`npm run build` 成功通过，无报错

## 修复图表闪烁 + 文化页图表不显示（Task 27-29）

### 问题
1. **全站图表闪烁**：每个页面进入时，图表先显示一下然后突然消失再显示
2. **文化页图表一直不显示**：建筑文化页面图表直接空白，无法看到任何图表

### 根因分析
- **闪烁**：`pageEnterAnimation()` 使用 `gsap.from('.chart-panel', { opacity: 0, ... })`，echarts 在 opacity=0 的容器中初始化，随后 opacity 动画到 1，某些浏览器/echarts 版本下会触发清空重绘
- **文化页不显示**：`.culture-content` 同时设置了 `display: none` + `visibility: hidden`，即使 active 状态覆盖为 `visible`，echarts 在初始化时可能因 visibility 层叠问题获取不到正确尺寸；另外 `safeInitChart` 使用 `setOption(option, true)`（notMerge），每次都会完全清空重绘

### 修复内容

#### 1. 全局闪烁修复（animation.js）
- 移除 `.chart-panel` 的 `opacity: 0` 动画，只保留 `y: 20` 位移动画
- 图表从始至终保持 `opacity: 1`，不再因 opacity 变化触发 echarts 重绘
- 移除 `onComplete` 中强制设置 `opacity/visibility` 的代码（不再需要）

#### 2. 文化页修复（culture/index.html + culture/main.js）
- **CSS**：移除 `.culture-content` 的 `visibility: hidden/visible`，只保留 `display: none/grid` 控制显示/隐藏
- **懒加载**：新增 `initializedTabs` Set，每个 tab 只在第一次切换时初始化图表，避免重复 `setOption` 导致的闪烁
- **safeInitChart**：`setOption(option, true)` → `setOption(option, false)`（默认 notMerge=false），避免清空重绘
- **init()**：移除双重 `requestAnimationFrame` resize，改为只在窗口 resize 时对当前 active tab 的图表执行 resize
- **GSAP 动画**：文化页卡片动画从 `from({ opacity: 0 })` 改为 `fromTo({ opacity: 0.3 }, { opacity: 1 })`，避免初始完全不可见

### 验证结果
- `npm run build` 构建成功
- playwright 截图验证 culture/achievement/scientist/literature/home 五个页面，所有图表均正常渲染，无空白
- 动态闪烁问题因静态截图无法完全验证，但根因（opacity 动画 + notMerge=true + visibility 层叠）已消除

## 修复构建后样式丢失 + 页面跳转闪烁（Task 34）

### 问题
1. `build.bat` / `npm run preview` 构建的网页样式丢失（截图确认）
2. `npm run dev` 时点击页面跳转，瞬间出现超大标题后恢复正常（flexible.js 延迟加载导致 rem 计算错误）

### 根本原因
- **CSS 引用方式错误**：先移除了 HTML `<link>` 改用 JS import，但 Vite 4.x MPA 构建时无法正确将 CSS link 注入 HTML
- **flexible.js 外部加载**：`<script src="/js/flexible.js">` 需要额外 HTTP 请求，页面跳转时新页面在 flexible.js 执行前用默认 font-size 渲染，导致 rem 单位元素尺寸异常
- **预览服务器 base 路径不匹配**：`vite.config.js` 中 build 用 `/ancient-architecture-viz/`，但 preview 的 command 也是 `serve`，导致 base 为 `/`，资源引用 404

### 修复内容
1. **恢复 HTML 中的 `<link>` 标签**：
   - 所有6个 HTML 文件恢复 CSS `<link>` 引用
   - 子页面用 `../../css/common.css`，根目录用 `./src/css/common.css`

2. **内联 flexible.js**：
   - 将 flexible.js 内容直接嵌入每个 HTML 的 `<script>` 标签中
   - 消除外部请求延迟，页面解析时立即设置 rem 基准
   - 解决跳转闪烁问题

3. **配置 `cssCodeSplit: false`**：
   - `vite.config.js` 中添加 `cssCodeSplit: false`
   - Vite 将 CSS 提取到共享文件并正确注入 `<link>` 到所有 HTML

4. **修复预览服务器 base 路径**：
   - `package.json`：`"preview": "vite preview --base /ancient-architecture-viz/"`
   - `build.bat`：同步更新 preview 命令

5. **移除 main.js 中的 CSS import**：
   - 避免 CSS 被重复加载
