## 三、详细安装步骤

### 3.1 环境准备

#### Windows

1. **安装Node.js**
   - 访问 https://nodejs.org/
   - 下载 LTS 版本（推荐 20.x）
   - 运行安装程序，按提示完成安装

2. **验证安装**
   ```powershell
   node --version
   npm --version
   ```

3. **安装Python（可选，用于数据爬虫）**
   - 访问 https://www.python.org/
   - 下载 Python 3.10+
   - 安装时勾选 "Add Python to PATH"

#### macOS

1. **使用Homebrew安装Node.js**
   ```bash
   brew install node
   ```

2. **验证安装**
   ```bash
   node --version
   npm --version
   ```

#### Linux (Ubuntu/Debian)

1. **安装Node.js**
   ```bash
   curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
   sudo apt-get install -y nodejs
   ```

2. **验证安装**
   ```bash
   node --version
   npm --version
   ```

### 3.2 项目安装

```bash
# 克隆项目
git clone https://gitee.com/your-username/ancient-architecture-visualization.git

# 进入项目目录
cd ancient-architecture-visualization

# 安装项目依赖
npm install

# 安装开发依赖（如需修改代码）
npm install -D
```

### 3.3 数据准备

项目已包含处理好的数据文件，位于 `data/processed/` 目录。

如需重新爬取数据：

```bash
# 进入爬虫目录
cd spider

# 安装Python依赖（如需要）
pip install requests beautifulsoup4

# 运行爬虫（Windows PowerShell）
$env:PYTHONUTF8="1"
python run_all_spiders.py

# 或运行爬虫（Linux/macOS）
PYTHONUTF8=1 python run_all_spiders.py

# 处理数据
cd ..
python scripts/data_processor.py
```

## 六、生产部署

### 6.1 构建

```bash
npm run build
```

构建输出：
- 目录：`dist/`
- 包含：HTML、CSS、JS、图片等资源
- 特点：已压缩、已优化、可直接部署

### 6.2 部署方式

#### 方式一：静态服务器

将 `dist/` 目录部署到任意静态服务器：

**Nginx配置示例**：
```nginx
server {
    listen 80;
    server_name your-domain.com;
    root /path/to/dist;
    index index.html;
    
    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

**Apache配置示例**：
```apache
<VirtualHost *:80>
    ServerName your-domain.com
    DocumentRoot /path/to/dist
    
    <Directory /path/to/dist>
        AllowOverride All
        Require all granted
    </Directory>
</VirtualHost>
```

#### 方式二：云存储/CDN

- **阿里云OSS**：上传 `dist/` 到OSS bucket，开启静态网站托管
- **腾讯云COS**：上传 `dist/` 到COS bucket，开启静态网站
- **GitHub Pages**：推送代码到GitHub，开启GitHub Pages
- **Vercel/Netlify**：连接Git仓库，自动部署

#### 方式三：Docker部署

```dockerfile
# Dockerfile
FROM nginx:alpine
COPY dist/ /usr/share/nginx/html/
EXPOSE 80
```

```bash
# 构建镜像
docker build -t ancient-architecture .

# 运行容器
docker run -d -p 8080:80 ancient-architecture
```

访问 http://localhost:8080

## 七、常见问题

### Q1: 安装依赖时出错

**问题**：`npm install` 报错

**解决**：
```bash
# 清除缓存
npm cache clean --force

# 使用淘宝镜像
npm config set registry https://registry.npmmirror.com

# 重新安装
npm install
```

### Q2: 开发服务器无法启动

**问题**：端口被占用

**解决**：
```bash
# 修改端口
npm run dev -- --port 3000

# 或在 vite.config.js 中修改
```

### Q3: 图表显示异常

**问题**：ECharts图表不显示或显示错误

**解决**：
1. 检查浏览器控制台是否有错误
2. 确认数据文件是否存在 `data/processed/`
3. 清除浏览器缓存，刷新页面

### Q4: 爬虫运行失败

**问题**：Python爬虫报错

**解决**：
```bash
# Windows设置编码
$env:PYTHONUTF8="1"

# 安装依赖
pip install requests beautifulsoup4

# 检查网络连接
```

### Q5: 移动端显示异常

**问题**：手机访问页面布局错乱

**解决**：
1. 确认 `responsive.css` 已正确引入
2. 检查浏览器是否支持CSS Grid和Flexbox
3. 使用真实手机测试，而非仅Chrome DevTools

### 8.1 核心技术

| 技术 | 版本 | 用途 |
|------|------|------|
| **Vite** | 5.4+ | 构建工具 |

- **Fetch API**：数据加载
- **Intersection Observer**：滚动动画触发

- **代码分割**：按需加载
- **Tree Shaking**：自动移除未使用代码
- **CSS提取**：生产环境提取CSS文件
