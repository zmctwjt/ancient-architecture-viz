### 二、作品概述

中国古代建筑是中华文明的重要载体，承载着数千年的智慧与美学。然而，关于古代建筑的史料分散在国家文物局、百度百科、中国非遗网等不同平台，数据庞杂且缺乏系统性的可视化呈现，普通公众难以直观了解其发展脉络与文化价值。

**"千年营造·华夏砖木"** 是一个面向大众的交互式数据可视化平台，以1911年以前的中国古代建筑为研究对象，从**建筑成就、杰出科学家、传世著作、建筑文化**四大维度出发，通过5个独立页面、20余种图表类型，将横跨2500余年（春秋至清末）的建筑发展历程以直观、生动的方式呈现出来。

平台数据涵盖：

| 维度 | 数据量 | 覆盖范围 |
|------|--------|----------|
| **建筑成就** | **115处**全国重点文物保护单位 | 11类建筑（寺庙26、园林20、城址11、墓葬10、祭祀建筑10、石窟9、楼阁6、桥梁8、民居6、官府5、皇宫4），遍布全国**25个省份** |
| **杰出科学家** | **20位**建筑领域代表人物 | 春秋（鲁班）至清代（雷发达、梁九），横跨9个朝代 |
| **传世著作** | **14部**建筑典籍文献 | 春秋《考工记》至清代《工部工程做法则例》 |
| **建筑文化** | **38条**文化形态详录 | 民居8类、官府5类、皇宫5类、桥梁8类、非遗技艺12类 |

所有数据均来自国家文物局、百度百科、中国非物质文化遗产网等权威公开来源，提供完整的Python爬虫源代码，数据采集过程透明可追溯。

### 三、核心功能详述

#### 3.1 首页——全局概览与朝代导航

首页作为平台的入口，帮助用户快速建立对中国古代建筑的全局认知：

- **数字滚动统计**：以GSAP驱动的数字滚动动画，展示建筑总数（115）、科学家人数（20）、传世著作（14）、建筑类别（11）四项核心指标
- **朝代导航卡片**：四大主题入口（建筑成就/杰出科学家/传世著作/建筑文化），支持点击特定朝代后进入对应子页面并自动过滤数据
- **朝代发展时间轴**：折线图展示各朝代建筑成就的数量演变趋势，支持点击查看各朝代详情
- **建筑特征雷达图**：从材料丰富度、工艺复杂度、地域分布广度、时代跨度等维度动态计算各建筑类型的特征对比
- **朝代筛选联动**：六大朝代（先秦/秦汉/魏晋/隋唐/宋元/明清）多选筛选，选中后进入子页面自动过滤对应数据

#### 3.2 建筑成就页——115处古建筑的技术与遗存

以5个核心图表全方位展示115处全国重点文物保护单位古建筑的分布与特征：

| 图表 | 类型 | 展示内容 |
|------|------|----------|
| 朝代分布玫瑰图 | 南丁格尔玫瑰图 | 各朝代建筑成就的分类占比，直观对比不同朝代遗存数量的差异 |
| 建筑类型极坐标柱状图 | 极坐标柱状图 | 11类建筑（寺庙/园林/城址/墓葬等）的数量分布 |
| 发展趋势堆叠面积图 | 堆叠面积图 | 不同建筑类型随朝代演变的趋势变化，揭示"寺庙持续领先、园林集中于明清"等规律 |
| 地理分布柱状图 | 柱状图 | 115处古建筑在全国25个省份的分布，北京/山西/河南等省份遗存最为丰富 |
| 各省排名条形图 | 横向条形图 | 按遗存数量降序排列的省份排名，一目了然 |

所有图表支持点击查看详情弹窗，弹窗内容从buildings.json的完整字段动态生成（包括名称、朝代、地点、类别、保护等级、建造年代等）。底部数据洞察面板提供分析结论与关键词标签。

#### 3.3 杰出科学家页——20位建筑大师的人物网络

以3种可视化方式展示从春秋鲁班到清代梁九共20位建筑领域代表人物：

| 图表 | 类型 | 展示内容 |
|------|------|----------|
| 力导向关系图 | 力导向网络图 | 人物→朝代→作品的关联网络，节点大小反映影响力，连线揭示师承与作品关系 |
| 影响力条形图 | 横向条形图 | 按朝代排序的综合影响力指数，展示鲁班、李诫、宇文恺等核心人物的突出贡献 |
| 重点人物卡片 | 信息卡片 | Top科学家的生平简介、代表作品、历史贡献 |

关系图中的朝代节点以不同颜色区分，科学家节点大小与影响力值成正比，作品节点按类型标记。支持按朝代筛选，点击任意节点可查看详情弹窗。

#### 3.4 传世著作页——14部建筑典籍的文献脉络

以4种图表展示从《考工记》到《工部工程做法则例》共14部建筑典籍的传承体系：

| 图表 | 类型 | 展示内容 |
|------|------|----------|
| 朝代分布柱状图 | 柱状图 | 各时期建筑著作的数量分布，北宋和明代为著作高峰期 |
| 旭日图 | 旭日图 | 朝代→著作的层级关系，内圈为朝代，外圈为具体著作 |
| 类型分布饼图 | 饼图 | 官书/民间/专著的比例分布 |
| 关键词散点图 | 散点图/气泡图 | 从文献中提炼的高频主题词及其权重分布 |

支持按朝代筛选，帮助用户从文献角度理解古代建筑知识的系统化传承。

#### 3.5 建筑文化页——四类建筑的深度文化解析

设置**四大标签页**（民居·官府·皇宫·桥梁），每类配备**6个主题图表**，共**24个图表**，采用懒加载策略（首次切换时才初始化），全方位展示建筑文化内涵：

##### 民居文化（8类民居详录）

| 图表 | 分析维度 |
|------|----------|
| 遗存数量分布饼图 | 四合院/土楼/徽派民居/吊脚楼/蒙古包/碉楼/干栏式建筑/窑洞的遗存分布 |
| 气候适应特征柱状图 | 从"气候适应"字段提取保温/防风/防潮/通风/防虫/防盗等关键词频次 |
| 结构类型柱状图 | 各类民居的建筑结构对比 |
| 材料构成环形图 | 土木/砖木/石木/竹木等主要材料的占比分布 |
| 全国重点遗存排名条形图 | 横向对比各类型全国重点文物保护单位数量 |
| 地区分布饼图 | 北方/南方/西北/西南等地区的民居类型分布 |

##### 官府文化（5类官府建筑）

| 图表 | 分析维度 |
|------|----------|
| 历代分布饼图 | 从"朝代"字段动态统计各朝代官府建筑数量 |
| 主要建筑元素柱状图 | 从"主要建筑"数组提取殿/堂/楼/阁/门/廊等建筑元素出现频次 |
| 文化内涵关键词柱状图 | 从"文化内涵"字段提取制度/权力/秩序/礼制等关键词频次 |
| 现存代表横向条形图 | 各官府建筑的全国遗存数量对比 |
| 建筑特征关键词柱状图 | 从"建筑特色"字段提取轴线/对称/等级/琉璃等特征频次 |
| 全国遗存数量对比 | 从文本字段提取数字进行量化对比 |

##### 皇宫文化（5座皇宫详录）

| 图表 | 分析维度 |
|------|----------|
| 历代规模柱状图 | 各皇宫占地面积（万平方米）对比 |
| 核心建筑类型柱状图 | 从"核心建筑"数组提取殿/堂/楼/门等建筑类型出现频次 |
| 世界遗产时间线 | 各皇宫列入世界遗产的年份排序 |
| 世界遗产状态饼图 | 已列入/未列入世界遗产的比例 |
| 规模vs建筑数量散点图 | x轴占地面积、y轴建筑间数、气泡大小为核心建筑数 |
| 现存宫殿规模指数 | 以故宫为基准(100)的相对规模指数 |

##### 桥梁文化（8座古桥详录）

| 图表 | 分析维度 |
|------|----------|
| 结构类型饼图 | 石拱桥/梁桥/索桥/浮桥/风雨桥等的结构分布 |
| 跨度对比横向条形图 | 各古桥跨度（米）的精确对比 |
| 材料演进柱状图 | 石/木/铁等材料的数量演变 |
| 世界之最（建造年份） | 按建造年代排序，展示从战国到清代的技术演进 |
| 技术特色关键词柱状图 | 从"技术特色"字段提取拱/梁/榫卯/敞肩/联拱等关键词频次 |
| 保护现状饼图 | 全国重点文物保护单位批次分布 |

所有文化页图表均基于**动态数据分析**——通过封装的6个工具函数（`countByField`、`extractKeywordFreq`、`extractBuildingElements`、`extractDynastyDist`、`extractNumberFromText`、`countArrayField`）从JSON原始数据中实时提取分析维度，确保图表内容基于真实数据而非硬编码。

### 四、技术实现

#### 4.1 技术架构

| 技术层 | 技术选型 | 版本 | 用途说明 |
|--------|----------|------|----------|
| 构建工具 | Vite | 4.5.0 | MPA多页面构建，按需加载，manualChunks分包 |
| 可视化 | ECharts | 5.4.3 | 20+交互式图表渲染（玫瑰图/旭日图/力导向图/极坐标图/散点图等） |
| 动画引擎 | GSAP | 3.12.2 | 页面过渡、数字滚动、叶片飘落、卡片入场 |
| 数据采集 | Python | 3.9+ | 4个爬虫脚本（国家文物局/百度百科/非遗网/故宫博物院） |
| 响应式 | flexible.js | 自研 | rem自适应适配（1rem=100px@1920px），覆盖1080P~4K |

#### 4.2 工程特色

- **多页面应用（MPA）架构**：6个独立页面（首页+4个主题页+过渡页），各页面独立加载，首屏性能优异
- **按需分包**：通过Vite的`manualChunks`将ECharts和GSAP分别打包，利用浏览器缓存提升二次加载速度
- **统一数据驱动**：所有图表数据从 `public/data/*.json` 动态加载，无硬编码数据，便于更新维护
- **懒加载优化**：建筑文化页tab切换采用懒加载策略，首次切换时才初始化对应标签页的24个图表
- **跨页面联动**：URL参数（`?dynasty=xxx`）驱动朝代筛选状态在首页与各子页面间无缝传递
- **动态数据分析**：6个通用工具函数从原始JSON数据实时提取关键词频次、建筑元素、朝代分布等分析维度

#### 4.3 代码规模

| 类别 | 文件数 | 代码行数 | 说明 |
|------|--------|----------|------|
| HTML | 6 | ~1,200行 | 首页+4个主题页+过渡页 |
| JavaScript | 18 | ~5,000行 | 页面逻辑+通用模块（动画/弹窗/洞察/工具） |
| CSS | 2 | ~1,300行 | 全局样式+响应式适配 |
| Python | 5 | ~1,800行 | 4个爬虫脚本+数据生成脚本 |
| 文档 | 9 | ~2,100行 | 设计说明书/简介/部署/开源说明等 |
| **合计** | **40** | **~11,400行** | |

### 五、视觉设计

#### 5.1 色彩体系

作品以深色科技风为基底，从传统建筑元素中提取色彩，构建"科技+古韵"的独特视觉体系：

| 色彩 | 色值 | 灵感来源 | 用途 |
|------|------|----------|------|
| 古铜金 | #C8A96E | 铜器、琉璃瓦 | 标题、高亮、装饰线、图表主色 |
| 青瓦色 | #4ECDC4 | 青砖黛瓦 | 图表渐变色、交互反馈色 |
| 朱砂红 | #E07B54 | 宫墙、门窗 | 重点标注、数据强调色 |
| 深夜墨 | #0D1117 | 夜空、墨汁 | 页面背景色 |
| 宣纸白 | rgba(255,255,255,0.9) | 宣纸 | 主要文字、坐标轴标签 |

图表配色使用ECharts `LinearGradient` 渐变（如古铜金→青瓦色、朱砂红→古铜金），增强视觉层次感。

#### 5.2 动效设计

- **飘落叶片**：银杏/枫叶/竹叶/柳叶四种形态，GSAP驱动旋转+飘移+透明度变化，契合古建筑主题
- **数字滚动**：首页统计数据的0→目标值滚动动画
- **卡片入场**：图表面板从下方滑入（仅y轴位移，避免opacity导致ECharts闪烁）
- **交互反馈**：卡片悬停缩放+边框发光、图表点击弹窗、脉冲呼吸动画
- **多层背景光晕**：顶部古铜金光晕+底部青瓦光晕+微妙网格纹理，营造沉浸式氛围

### 七、创新与特色

1. **四维度知识图谱**：从"成就-人物-文献-文化"四大维度系统梳理中国古代建筑，涵盖115处古建筑、20位科学家、14部著作、38类文化形态，形成较完整的古代建筑知识图谱
2. **深度文化解析**：建筑文化页以四类建筑（民居/官府/皇宫/桥梁）×6个分析维度×24个图表，实现建筑文化的全方位、多角度可视化
3. **动态数据分析**：封装6个通用工具函数，从原始JSON数据实时提取关键词频次、建筑元素、朝代分布等分析维度，确保图表内容真实有分析意义
4. **视觉融合创新**：深色科技风+古建筑色彩元素的融合，古铜金/青瓦色/朱砂红的渐变配色营造"科技+古韵"的独特风格
5. **全图表可交互**：所有20+图表支持点击查看详情弹窗，页面间支持朝代筛选联动跳转，降低信息获取门槛
6. **工程化程度高**：MPA架构、按需分包、懒加载、跨页面URL参数联动、GSAP与ECharts时序分离等技术手段保障流畅体验
7. **全流程开源**：从数据采集（4个Python爬虫）到前端展示（40文件/11,400行代码）的全流程代码均开源，附9份技术文档
