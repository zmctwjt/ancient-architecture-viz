## 三、详细数据来源

### 3.1 建筑成就数据

**主要来源**：国家文物局全国重点文物保护单位名录

**备用来源**：
- 重庆市文物局政务服务平台
- 国务院核定公布全国重点文物保护单位名单

**数据字段**：
```json
{
  "name": "建筑名称",
  "province": "所在省份",
  "city": "所在城市",
  "dynasties": ["始建朝代", "重建朝代"],
  "type": "建筑类型（民居/官府/皇宫/桥梁）",
  "batch": "公布批次（第X批）",
  "description": "简介",
  "cultural_value": "文化价值"
}
```

**数据示例**：
- 北京故宫（明清皇宫，第1批）
- 赵州桥（隋代桥梁，第1批）
- 平遥古城（明清县城，第2批）

**数据验证**：
- 官网链接：https://www.ncha.gov.cn/
- 可通过"全国重点文物保护单位名单"公开文件交叉验证

## 四、爬虫脚本说明

### 4.1 脚本列表

| 脚本名 | 功能 | 数据来源 |
|--------|------|----------|
| `spider_ncha.py` | 爬取全国重点文物保护单位 | 国家文物局 |
| `spider_architect.py` | 爬取古代建筑师词条 | 百度百科 |
| `spider_books.py` | 爬取建筑典籍词条 | 百度百科 |
| `spider_culture.py` | 爬取建筑文化数据 | 中国非遗网 |
| `run_all_spiders.py` | 批量运行所有爬虫 | — |

### 4.2 爬虫技术说明

- **框架**：Python requests + BeautifulSoup4
- **反爬策略**：设置User-Agent、请求间隔、异常重试
- **编码处理**：统一使用UTF-8编码，避免Windows GBK问题
- **数据存储**：JSON格式，保留原始数据结构

### 4.3 运行方式

```bash
# 设置编码环境变量
$env:PYTHONUTF8="1"

# 运行单个爬虫
python spider/spider_ncha.py

# 批量运行所有爬虫
python spider/run_all_spiders.py
```

## 五、数据处理流程

### 5.1 原始数据

存储位置：`data/raw/`

- `ncha_ancient_buildings.json` — 原始爬取的建筑数据
- `architects.json` — 原始爬取的科学家数据
- `books.json` — 原始爬取的著作数据
- `culture.json` — 原始爬取的文化数据

### 5.2 数据清洗

**清洗脚本**：`scripts/data_processor.py`

**清洗内容**：
1. 统一字段命名和数据格式
2. 补充缺失值
3. 生成统计汇总数据
4. 构建关系图数据（节点和边）
5. 构建旭日图层级数据
6. 构建时间轴序列数据

### 5.3 处理后数据

存储位置：`data/processed/`

- `buildings_processed.json` — 建筑成就统计数据
- `architects_processed.json` — 科学家统计数据（含关系图）
- `books_processed.json` — 著作统计数据（含旭日图）
- `culture_processed.json` — 建筑文化分类数据
- `data_summary.json` — 数据汇总报告

## 六、数据质量保证

### 6.1 真实性

- 所有数据来自官方或权威来源
- 提供数据源链接，可溯源验证
- 不虚构、不夸大任何数据
