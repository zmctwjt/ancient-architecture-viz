## 三、组件详细说明

### 3.1 Vite

**项目地址**：https://vitejs.dev/

**许可证**：MIT License

**版权信息**：
```
Copyright (c) 2019-present, Yuxi (Evan) You and Vite contributors
```

**使用方式**：
```bash
npm install vite --save-dev
```

**用途说明**：
- 项目构建工具，支持多页面应用（MPA）配置
- 提供开发服务器（port 5173）与热更新（HMR）
- 代码分割（Code Splitting）与 Tree Shaking
- 将 ECharts 和 GSAP 单独打包为独立 Chunk，优化加载性能
- 通过 `manualChunks` 配置实现 vendor 分离

**本项目配置要点**：
- 6个页面入口（index + achievement + scientist + literature + culture + transition）
- `public/js/flexible.js` 直接复制到构建产物，不参与打包
- 开发 SourceMap 启用，便于调试

**许可证全文**：见 `licenses/MIT_LICENSE`

### 3.3 GSAP (GreenSock Animation Platform)

**项目地址**：https://greensock.com/gsap/

**许可证**：Standard License（免费用于开源、教育及非商业项目）

**版权信息**：
```
Copyright (c) 2008-2024, GreenSock. All rights reserved.
```

**使用方式**：
```bash
npm install gsap
```

**用途说明**：
- 页面入场动画（标题、卡片、图表面板依次淡入）
- 飘落叶片背景动效（银杏/枫叶/竹叶/柳叶）
- 统计数字滚动动画（countUp效果）
- 卡片悬停缩放与阴影效果
- 朝代过渡页节点缩放动画

**使用的核心API**：
- `gsap.from()` / `gsap.to()` — 元素属性渐变
- `gsap.timeline()` — 时间轴序列动画
- `gsap.stagger()` — 错开动画时序

**许可证说明**：
GSAP在开源项目、教育竞赛及非商业项目中可以免费使用。本作品作为大学生计算机设计大赛参赛作品，符合免费使用条件。如后续用于商业用途，需购买相应授权。

### 3.4 flexible.js

**来源**：开源移动端适配方案（阿里巴巴手淘团队）

**使用方式**：直接引入，非 npm 包
```html
<script src="/js/flexible.js"></script>
```

**用途说明**：
- 基于 rem 单位的响应式适配方案
- 以 1920px 设计稿为基准，1rem = 100px
- 限制 rem 范围 [50px, 150px]，防止极端屏幕下的布局错乱
- 所有页面统一通过 `<script src>` 引入，Vite 将 `public/js/flexible.js` 直接复制到构建产物

**原创性说明**：
- 基础逻辑来源于开源 flexible.js
- 根据本项目 1920px 大屏设计需求进行了参数调优
- 添加最小/最大 rem 限制，适配竞赛评审环境

| JSON 数据 | 11 | — |
| **总计** | **54** | **~27,000** |

### 4.2 核心自定义模块

#### 1. 公共工具模块（`src/js/common/`）

| 文件 | 功能 | 行数 |
|------|------|------|
| `utils.js` | 防抖/节流、数字格式化、数据加载、图表响应式、配色常量 | 183 |
| `animation.js` | 页面入场动画、数字滚动、卡片悬停、飘落叶片 | 193 |
| `infoModal.js` | 通用信息弹窗（支持ESC/点击背景关闭/动画） | 189 |
| `insights.js` | 数据分析结论模块（4个页面的洞察数据） | 126 |

**原创性说明**：
- `infoModal.js` 为完全自主封装的弹窗组件，支持图表点击回调
- `insights.js` 提炼了各页面的核心数据结论，非通用库
- `animation.js` 中飘落叶片效果为原创设计，灵感源于古建筑庭院

#### 2. 动效系统（`src/js/effects/`）

| 文件 | 功能 | 行数 |
|------|------|------|
| `index.js` | 统一导出 | 32 |
| `pageTransition.js` | 页面过渡动画系统 | 181 |
| `leafAnimation.js` | 飘落叶片效果（银杏/枫叶/竹叶/柳叶） | 197 |
| `interactions.js` | 交互动效（悬停/点击/滚动/涟漪） | 274 |

**原创性说明**：
- 叶片类型、颜色、飘落轨迹参数均为自主设计
- 移动端自动降级为简化版效果（减少叶片数量）
- `intersectionObserver` 实现滚动触发动画

#### 3. 页面图表模块（`src/view/*/main.js`）

| 页面 | 文件 | 图表数 | 行数 |
|------|------|--------|------|
| 首页 | `home/main.js` | 2 | 376 |
| 建筑成就 | `achievement/main.js` | 5 | 543 |
| 杰出科学家 | `scientist/main.js` | 3 | 447 |
| 建筑著作 | `literature/main.js` | 3 | 437 |
| 建筑文化 | `culture/main.js` | 24（4标签×6） | 445 |

**原创性说明**：
- 所有图表配置均为针对古建筑数据定制
- 配色方案（古铜金/青瓦色/朱砂红）为项目原创视觉设计
- 数据洞察与交互逻辑（弹窗、跳转）为自主实现

#### 4. 数据层（`spider/` + `scripts/`）

| 文件 | 功能 |
|------|------|
| `spider/spider_ncha.py` | 国家文物局古建筑数据爬取 |
| `spider/spider_architect.py` | 建筑师数据爬取 |
| `spider/spider_books.py` | 建筑著作数据爬取 |
| `spider/spider_culture.py` | 非遗建筑文化数据爬取 |
| `scripts/data_processor.py` | 数据清洗与结构化处理 |

**原创性说明**：
- 爬虫脚本针对特定数据源定制开发
- 数据处理脚本生成多种图表所需的专有格式（关系图节点边、旭日图层级、时间轴序列）
