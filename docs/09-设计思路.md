# 设计思路

## 千年营造·华夏砖木——中国古代建筑数据可视化平台

---

## 一、设计理念

### 1.1 核心思想

**"以数为媒，以艺载道"**

- **数据为本**：所有展示内容基于真实可信的数据源，确保科学性和准确性
- **艺术呈现**：采用符合古建筑美学特征的视觉设计，营造沉浸式体验
- **文化传承**：通过交互设计，引导用户深入了解古建筑背后的文化内涵

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| **真实性** | 数据来源权威可溯，不虚构、不夸大 |
| **完整性** | 覆盖建筑成就、科学家、著作、文化四个维度 |
| **艺术性** | 视觉风格契合古建筑主题，色彩取自传统建筑元素 |
| **流畅性** | 页面过渡自然，交互反馈及时，加载性能优化 |
| **实用性** | 功能实用，操作简便，适配多种设备 |

## 三、视觉设计思路

### 3.1 色彩设计

色彩灵感来源于中国传统建筑元素：

| 色彩名称 | 色值 | 灵感来源 | 使用场景 |
|----------|------|----------|----------|
| **古铜金** | `#C8A96E` | 铜器、琉璃瓦 | 主色调、强调元素 |
| **青瓦色** | `#4ECDC4` | 青砖黛瓦 | 辅助色、图表配色 |
| **朱砂红** | `#E07B54` | 宫墙、门窗 | 点缀色、重要数据 |
| **深夜墨** | `#0d1117` | 夜空、墨汁 | 背景色 |
| **宣纸白** | `rgba(255,255,255,0.9)` | 宣纸 | 主要文字 |

**设计 rationale**：
- 深色背景营造沉浸式体验，突出数据主体
- 古铜金、青瓦色、朱砂红均取自传统建筑元素，增强文化认同感
- 高对比度确保数据可读性

### 3.2 字体设计

- **标题字体**：思源宋体（Noto Serif SC）—— 体现传统文化韵味
- **正文字体**：思源黑体（Noto Sans SC）—— 保证阅读清晰度
- **数字字体**：DIN Alternate —— 现代感与数据专业性

### 3.3 动效设计

**飘落叶片效果**：
- 替代传统的流星效果，更符合古建筑主题
- 四种叶片类型：银杏叶（秋）、枫叶（秋）、竹叶（春）、柳叶（春）
- 使用GSAP实现流畅的飘落动画，包含旋转和飘移

**页面过渡**：
- 标题淡入 + 图表面板依次入场
- 卡片悬停缩放 + 阴影效果
- 数字滚动动画展示统计数据

## 四、数据可视化设计

### 4.1 图表选型原则

| 数据类型 | 选用图表 | 选型理由 |
|----------|----------|----------|
| 占比/分布 | 玫瑰图、饼图、环形图 | 直观展示各部分占比 |
| 时间序列 | 折线图、面积图、时间轴 | 展示演变趋势 |
| 地理分布 | 中国地图 | 展示空间分布特征 |
| 关系网络 | 力导向关系图 | 展示人物-作品-朝代关联 |
| 层级结构 | 旭日图 | 展示分类层级关系 |
| 多维对比 | 雷达图 | 对比多个维度的特征 |

### 4.2 交互设计

- **悬停提示**：鼠标悬停显示详细数据
- **点击下钻**：点击图表元素展开详情弹窗
- **标签切换**：建筑文化页支持四类建筑切换
- **页面过渡**：平滑的页面切换动画

## 五、响应式设计

### 5.1 断点设计

| 断点 | 设备 | 网格列数 | 特点 |
|------|------|---------|------|
| <375px | 小屏手机 | 1列 | 简化布局 |
| 375-767px | 手机 | 2列 | 统计/导航2列 |
| 768-1023px | 平板 | 2列 | 标准平板布局 |
| 1024-1439px | 小桌面 | 3列 | 标准桌面 |
| >=1440px | 大桌面 | 3列 | 最大宽度1920px |

### 5.2 适配策略

- 移动端禁用复杂动画，减少叶片数量
- ECharts配置自动适配（字体大小、标签旋转）
- 触摸手势支持（滑动切换）
- 减少动画偏好支持 `prefers-reduced-motion`

## 六、创新点

### 6.1 内容创新

1. **多维度整合**：首次将建筑成就、科学家、著作、文化四个维度整合在一个平台
2. **数据驱动**：基于真实权威数据，而非虚构内容
3. **文化传承**：不仅展示数据，更注重文化内涵的传递

### 6.2 技术创新

1. **主题化动效**：飘落叶片替代传统粒子效果，契合古建筑主题
2. **响应式适配**：完善的移动端适配方案
3. **性能优化**：移动端自动降级复杂动画，保证流畅性

### 6.3 设计创新

1. **色彩体系**：从传统建筑中提取色彩，营造沉浸式体验
2. **视觉层次**：深色背景 + 亮色图表，突出数据主体
3. **动效节奏**：动画时长和缓动函数精心设计，避免视觉疲劳

## 七、设计重点与难点

### 7.1 设计重点

1. **数据真实性**：确保所有数据来源权威、可溯源
2. **视觉一致性**：保持整体视觉风格的统一性
3. **用户体验**：平衡信息密度与可读性
4. **性能优化**：保证在各种设备上的流畅运行

### 7.2 技术难点

1. **数据获取**：古建筑数据分散，需要多渠道整合
2. **图表适配**：ECharts在不同尺寸屏幕上的自适应
3. **动效性能**：复杂动画在移动端的性能优化
4. **浏览器兼容**：确保主流浏览器的兼容性

### 7.3 解决方案

| 难点 | 解决方案 |
|------|----------|
| 数据获取 | 编写爬虫脚本，从国家文物局、百度百科等权威来源获取 |
| 图表适配 | 封装响应式适配工具，根据屏幕尺寸动态调整配置 |
| 动效性能 | 检测设备性能，移动端自动降级简化动画 |
| 浏览器兼容 | 使用Vite构建，自动处理兼容性问题 |
