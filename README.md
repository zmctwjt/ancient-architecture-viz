## 📖 项目简介

**"千年营造·华夏砖木"** 是一个基于数据可视化的中国古代建筑展示平台。作品以"弘扬中华优秀传统文化"为主题，通过数据可视化的方式，生动展现中国古代建筑在**建筑成就、杰出科学家、传世著作、建筑文化**四个维度的丰富内涵。

### 🎯 核心特色

- **数据真实可信**：所有数据来自国家文物局、百度百科、中国非遗网等权威来源
- **视觉风格独特**：深色科技风 + 古风配色，飘落叶片动效契合古建筑主题
- **图表丰富多样**：20+ 图表类型，包括玫瑰图、力导向关系图、旭日图等
- **响应式适配**：完美适配桌面端、平板、手机等多种设备
- **交互体验流畅**：GSAP动画、页面过渡、悬停效果等精心设计的交互

## 🚀 快速开始

### 环境要求

- Node.js >= 16.0.0
- npm >= 8.0.0

### 安装步骤

```bash
# 克隆项目
git clone https://gitee.com/your-username/ancient-architecture-visualization.git

# 进入项目目录
cd ancient-architecture-visualization

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

访问 http://localhost:5173 查看项目

### 构建生产版本

```bash
npm run build
```

构建输出位于 `dist/` 目录

## 📊 数据说明

### 数据来源

| 数据类别 | 数据来源 | 数据量 |
|----------|----------|--------|
| **建筑成就** | 国家文物局全国重点文物保护单位名录 | 43条 |

| **传世著作** | 百度百科 + 故宫博物院 | 14部 |
| **建筑文化** | 中国非物质文化遗产网 + 学术文献 | 38类 |

### 数据文件

- 原始数据：`data/raw/`
- 处理后数据：`data/processed/`
- 数据清洗脚本：`scripts/data_processor.py`
